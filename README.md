# Game Belajar Pemrograman Web

Kumpulan game latihan untuk siswa TKJ SMK Sunan Drajat Lamongan. Semua game berjalan offline di browser (satu file HTML, tanpa internet/CDN) dan nyaman dipakai di HP.

`index.html` adalah menu utama berisi:

- 🎯 Selector Sniper — selector CSS
- 🦆 Taman Flexbox & Grid
- 🐞 Bug Hunter — cari kesalahan HTML/CSS/JavaScript
- 🏎️ Subnet Racer — subnetting
- 🕵️ SQL Detective — query SQL
- 🤖 Robot Maze — logika pemrograman
- 🧩 Coding Puzzle Portofolio (juga tersedia terpisah: `coding_puzzle_portofolio v3.html`)

## Hosting dengan GitHub Pages

Settings → Pages → Build and deployment → Source: *Deploy from a branch* → Branch: `main` / `(root)`.
Alamat: `https://azizi07.github.io/puzzle-pemrograman-web/`

Progres siswa (bintang & skor) tersimpan di browser perangkat masing-masing.
