🔑 Kunci Jawaban — Coding Puzzle Portofolio

Untuk guru · dibuat otomatis dari data puzzle, jadi selalu sama dengan file puzzle

Cara pakai
  • Pemeriksa di puzzle menilai per aturan CSS: properti boleh urut bebas di dalam aturan, tetapi harus berada di aturan yang benar dan aturan harus ditutup }. Urutan antar aturan CSS boleh bebas.
  • Potongan HTML harus urut sesuai kunci di bawah (atas → bawah halaman).
  • Jalan pintas di puzzle: buka file dengan ?guru di akhir alamat (misal coding_puzzle_portofolio.html?guru) untuk memunculkan tombol 🔑 Kunci yang menyusun jawaban otomatis.
